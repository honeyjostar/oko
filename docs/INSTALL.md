# Установка и запуск по шагам (Windows)

Без модели всё ставится минут за 15. Модель Qwen3-VL весит около 6 ГБ — плюс время на скачивание.

**Что нужно:** Windows 10 или 11, 8 ГБ оперативной памяти и 10 ГБ свободного места. Для основной модели нужна видеокарта с 8 ГБ видеопамяти. Без видеокарты модель тоже запустится, но один документ будет читаться минутами.

---

## Шаг 1. Python

1. Открой [python.org/downloads](https://www.python.org/downloads/) и скачай Python 3.12 (подойдёт любой 3.11 или новее).
2. В первом окне установщика **обязательно отметь «Add python.exe to PATH»**, потом нажми *Install Now*.
3. Проверка: `Win + R` → `cmd` → в окне набери:
   ```
   python --version
   ```
   Должно появиться `Python 3.12.x`.

## Шаг 2. Tesseract — базовая линия для сравнения

1. Открой [страницу сборки UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki) и скачай `tesseract-ocr-w64-setup-5.x.x.exe`.
2. В установщике на шаге *Choose Components* раскрой **Additional language data** и отметь **Russian**.
3. Путь установки оставь по умолчанию — OKO найдёт программу сам. Если поставил в другое место, перед запуском укажи путь:
   ```
   set OKO_TESSERACT=D:\Tesseract-OCR\tesseract.exe
   ```

Без Tesseract демо тоже работает, просто не будет движка для сравнения.

## Шаг 3. Скачать проект

Вариант через git:
```
git clone https://github.com/honeyjostar/oko.git
cd oko
```
Или на странице репозитория нажми *Code → Download ZIP* и распакуй архив.

## Шаг 4. Поставить зависимости

Дважды щёлкни `scripts\setup.bat`. Скрипт создаст окружение `.venv` и поставит библиотеки — это 3–5 минут. В конце он проверит, всё ли на месте:
```
✓ tesseract: готов
✗ vlm: Сервер модели не отвечает ...
```
Строка про vlm с крестиком — это нормально: модель подключаем на шаге 6.

## Шаг 5. Открыть демо

Дважды щёлкни `scripts\demo.bat`. Демо откроется в браузере по адресу http://localhost:8501.

| Вкладка | Что там |
|---|---|
| Распознать | выбрать документ из набора или загрузить свой, сравнить ответ с правильным, посмотреть проверки, сохранить в базу |
| Поиск | запрос обычной фразой: «хендай крета с ЭПТС», «машины Пановой», «мерседесы и бмв новее 2017» |
| Качество | цифры и графики замера |
| Набор данных | документы с разметкой, «фото телефоном» и все 12 искажений |

Пока модель не подключена, на вкладке «Распознать» выбери движок **Tesseract**.

## Шаг 6. Подключить модель Qwen3-VL 8B

### Вариант А — LM Studio (проще)

1. Скачай и установи [LM Studio](https://lmstudio.ai).
2. В поиске моделей набери `qwen3-vl-8b`, выбери **Qwen3-VL 8B Instruct** и скачай вариант на ~6 ГБ (обычно `Q4_K_M`).
3. Перейди на вкладку **Developer**, вверху выбери скачанную модель и запусти сервер (*Start Server*). Порт по умолчанию — `1234`, его не меняй.
4. Проверка (в папке проекта):
   ```
   .venv\Scripts\activate
   python -m oko doctor
   ```
   Должно быть `✓ vlm: готов`. Как бы LM Studio ни назвала модель (например, `qwen/qwen3-vl-8b`), OKO найдёт её по имени сам.

### Вариант Б — Ollama

```
ollama pull qwen3-vl:8b
set OKO_VLM_URL=http://127.0.0.1:11434/v1
```

## Шаг 7. Замерить качество модели

Дважды щёлкни `scripts\eval_vlm.bat`. Скрипт:

1. создаст полный набор в папке `data\` (300 машин, 900 документов; 10–15 минут, если набора ещё нет);
2. прогонит модель по тестовой части — 273 документа, скан и фото;
3. сделает стресс-тест — 12 искажений × 4 уровня силы;
4. соберёт отчёт: `docs\REPORT.md`, графики в `docs\img\` и таблицу результатов в `README.md`.

На видеокарте с 8 ГБ это примерно 1–2 часа. Прогон можно прервать (`Ctrl + C`) и запустить снова — готовое не пересчитывается.

## Командная строка

Сначала активируй окружение: `.venv\Scripts\activate`.

| Команда | Что делает |
|---|---|
| `python -m oko extract фото.jpg` | распознать документ моделью |
| `python -m oko extract фото.jpg --engine tesseract` | то же через Tesseract |
| `python -m oko generate --out data` | создать набор данных |
| `python -m oko eval --engine vlm --data data` | замер на тестовой части |
| `python -m oko robustness --engine vlm --data data` | стресс-тест |
| `python -m oko report --data data` | отчёт и графики |
| `python -m oko db-fill --data data` | заполнить демо-базу |
| `python -m oko search "белые киа 2018 года"` | поиск по базе |
| `python -m oko doctor` | проверить, всё ли установлено |
| `python -m pytest` | автотесты |

## Если что-то не работает

| Что видишь | Что делать |
|---|---|
| `"python" не является внутренней или внешней командой` | Переустанови Python с галочкой «Add python.exe to PATH» |
| `Tesseract не установлен` | Шаг 2. Если ставил не в стандартную папку — задай `OKO_TESSERACT` |
| `У Tesseract нет русского языка` | Запусти установщик Tesseract ещё раз и отметь Russian |
| `Сервер модели не отвечает` | В LM Studio запусти сервер на вкладке Developer; порт должен быть 1234 |
| `На сервере нет модели «qwen3-vl-8b»` | В сообщении перечислены модели, которые есть на сервере. Укажи нужную: `set OKO_VLM_MODEL=<имя>` |
| `Результаты ... посчитаны на другом наборе` | Набор создан не с тем seed или другой версией Faker. Поставь зависимости из `requirements.txt` и пересоздай набор: `python -m oko generate --out data` |
| Модель отвечает очень долго | Закрой игры и другие программы, которые занимают видеокарту; в LM Studio выставь загрузку модели в видеопамять (GPU offload) на максимум |
